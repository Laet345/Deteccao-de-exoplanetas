1. VISÃO GERAL DO PROJETO E DOS DADOS
--------------------------------------------------------------------------------
• Base de Dados: Wisconsin Diagnostic Breast Cancer (WDBC)
  - Arquivos: data/raw/wdbc.data e data/raw/wdbc.names
  - Amostras: 569 pacientes
  - Atributos: 32 colunas no total:
      1) ID do paciente (identificador único, não preditivo)
      2) Diagnóstico (Target: 'M' = Maligno [212], 'B' = Benigno [357])
      3 a 32) 30 características numéricas contínuas extraídas de imagens
              digitalizadas de punção aspirativa por agulha fina (FNA).
              Representam média (mean), erro padrão (se) e pior valor (worst)
              de 10 propriedades geométricas dos núcleos celulares:
              - radius, texture, perimeter, area, smoothness, compactness,
                concavity, concave points, symmetry, fractal dimension.
  - Dados faltantes: Nenhum (base completa, sem NaNs).

• Pergunta Fundamental / Hipótese Científica:
  "É possível predizer com alta confiabilidade se uma lesão mamária é maligna 
   ou benigna a partir das características morfométricas celulares, minimizando 
   ao máximo os falsos negativos (diagnósticos de falso benigno)?"

• Desafios Científicos Relevantes:
  - Multicolinearidade acentuada (ex.: raio, perímetro e área são altamente correlacionados).
  - Ligeiro desbalanceamento de classes (~62,7% Benigno vs ~37,3% Maligno).
  - Escalas e grandezas muito distintas entre atributos (ex.: area ~ 1000 vs smoothness ~ 0.1).
  - Criticidade do domínio médico (priorização do Recall/Sensibilidade da classe Maligna).

2. ESTRUTURA METODOLÓGICA (SEGUINDO OS 10 PASSOS DO PROF. FRANCISCO)
--------------------------------------------------------------------------------
Passo 1: Preparação e Limpeza dos Dados
  - Inserção dos cabeçalhos corretos (a base bruta vem sem nomes de colunas).
  - Remoção da coluna de ID (irrelevante para predição).
  - Mapeamento da variável alvo ('B' -> 0, 'M' -> 1).
  - Verificação de tipos, consistência e outliers físicos.

Passo 2: Descrição Estatística Completa
  - Medidas de tendência central (média, mediana).
  - Medidas de dispersão (desvio padrão, variância, IQR).
  - Medidas de forma (assimetria/skewness, curtose).
  - Estatísticas estratificadas por classe (Maligno vs Benigno).

Passo 3: Análise Exploratória e Reconhecimento de Padrões
  - Matrizes de correlação (Pearson e Spearman) com heatmap.
  - Pairplots das variáveis mais discriminantes (ex.: worst concave points, worst area).
  - Boxplots comparativos entre Benigno e Maligno para cada família de features.
  - Análise de densidade (KDE plots).

Passo 4: Formulação e Enquadramento do Problema
  - Problema principal: Classificação Supervisionada Binária (0 = Benigno, 1 = Maligno).
  - Abordagem complementar: Não-supervisionada (Agrupamento / Clustering com K-Means 
    e Mistura Gaussiana) para verificar a separabilidade intrínseca dos dados.

Passo 5: Métodos de Aprendizado e Ajuste de Modelos
  - Modelos a testar:
      1. Regressão Logística (modelo linear baseline)
      2. K-Nearest Neighbors - KNN (baseado em distância)
      3. Support Vector Machine - SVM (com kernels Linear e RBF)
      4. Naive Bayes Gaussiano (probabilístico)
      5. Random Forest / Decision Tree (baseados em árvores e ensembles)
  - Validação Cruzada Estratificada (Stratified K-Fold, k=5 ou k=10) para evitar vazamento.
  - Ajuste de hiperparâmetros com GridSearchCV / RandomizedSearchCV.

Passo 6: Comparação e Avaliação dos Modelos
  - Métricas: Acurácia, Precisão, Recall (Sensibilidade), Especificidade, F1-Score e ROC-AUC.
  - Matrizes de confusão normalizadas para cada modelo.
  - Curvas ROC e curvas Precision-Recall comparativas.
  - Análise de custo de erro médico (Falso Negativo custa muito mais que Falso Positivo).

Passo 7: Otimização com Projeção, Seleção e Transformações
  - Escalonamento: Comparar StandardScaler vs MinMaxScaler vs RobustScaler.
  - Redução de dimensionalidade: PCA (Análise de Componentes Principais) e t-SNE.
  - Seleção de atributos (Feature Selection):
      * Remoção por alta colinearidade (VIF ou corte de correlação > 0.90).
      * Seleção univariada (SelectKBest / ANOVA F-test).
      * RFE (Recursive Feature Elimination) ou importâncias do Random Forest.
  - Re-treinamento e comparação: o desempenho melhorou com menos variáveis?

Passo 8: Resultados Finais Consolidados
  - Tabela consolidada comparando todos os modelos (baseline vs dados reduzidos vs otimizados).
  - Identificação do melhor classificador segundo as métricas clínicas.

Passo 9: Discussão dos Resultados e Limitações
  - Interpretação das features mais decisivas na classificação do tumor.
  - Discussão sobre explicabilidade clínica vs complexidade do modelo.
  - Análise crítica de desafios: tamanho da amostra (569 casos), generalização para 
    novas populações e propostas de trabalhos futuros.

Passo 10: Sumário Executivo e Síntese
  - Resumo das descobertas, síntese visual dos gráficos principais e conclusão do projeto.

INTEGRANTE 3: Redução de Dimensionalidade, Seleção de Features e Clustering
--------------------------------------------------------------------------
• Atribuições:
  1. Estudo não-supervisionado: aplicação de K-Means e/ou Mistura de Gaussianas (GMM)
     para avaliar se os dados se agrupam naturalmente em 2 clusters (benigno vs maligno)
     sem os rótulos originais, medindo o Silhouette Score.
  2. Aplicação de PCA (Principal Component Analysis):
     - Gráfico de variância explicada acumulada (Scree Plot / curva de cotovelo de componentes).
     - Projeção 2D e 3D das classes usando os primeiros componentes principais.
  3. Projeção t-SNE para visualização não-linear da separabilidade dos dados.
  4. Seleção de atributos (Feature Selection):
     - Método por eliminação de colinearidade (limiar de corte de correlação).
     - Método univariado (SelectKBest com f_classif ou mutual_info_classif).
     - Método Wrapper / Embutido (RFE com Random Forest ou Regressão Logística L1/Lasso).
• Entregas:
  - Gráficos de PCA e t-SNE com separação clara das classes.
  - Lista ranqueada dos atributos mais informativos e criação de datasets com dimensões

     - Regressão Logística (com regularização L1/L2)

     - Naive Bayes Gaussiano
     - Árvores de Decisão / Random Forest

     - Cenário A: Todas as 30 variáveis originais padronizadas.
     - Cenário B: Dados transformados via PCA (ex.: mantendo 95% da variância).
     - Cenário C: Apenas o subconjunto das features selecionadas (Top-K / RFE).
• Entregas:
  - Tabela com os melhores hiperparâmetros de cada classificador.
  - Código reprodutível com os modelos treinados e ajustados.
